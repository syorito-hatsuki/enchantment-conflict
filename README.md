## About The Project

![In-Game ScreenShot][screenshot]

Add conflict / incompatibility tooltips to enchantment books to help you find out what enchantments are incompatible
with each other.

<p align="right">(<a href="#readme-top">back to top</a>)</p>

Default keybinds:
